# Fitness Tracker UX Starter (Android/Kotlin, Jetpack Compose)

## What you get
- Glanceable rings (steps/move/HR) with `CircularProgressIndicator`.
- Haptics utility with 3 example patterns.
- Voice command trigger using `RecognizerIntent` (e.g., "start run", "stop workout").

## How to use
1. Open the folder in **Android Studio**.
2. Let Gradle sync. If prompted, accept to update plugin/SDK versions.
3. Run on an Android device/emulator.
